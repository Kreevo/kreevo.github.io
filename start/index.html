Install any Kreevo panel in 5 steps

MotionType, Kreevo Titles, Kinetic, Kreevo Ease, Kreevo Voice, CreatorStash and MotionType Lite all install the same way. Crash Guard and the SFX Pack are different, see below.

  1. Download the ZIP from your Gumroad receipt email, or from your Gumroad library. Bought the Bundle? Each tool is its own product in your library, with its own download and license key.
  2. Unzip it first. Right-click the ZIP > Extract All > Extract. Double-click the ZIP. A normal folder appears next to it. Don't run anything from inside the ZIP preview, it won't work.
  3. Close After Effects and Premiere Pro.
  4. Run the installer inside the folder. Double-click the file that ends in (Windows).bat, for example Install MotionType (Windows).bat. A black window opens, copies the files and says it's done. Right-click the file that ends in (Mac).command, for example Install MotionType (Mac).command, then Open > Open.
    "Windows protected your PC"? That's normal for small independent tools. Click More info > Run anyway.
    "Apple could not verify…"? Don't move it to the Trash. Click Done, open System Settings > Privacy & Security, scroll down and click Open Anyway. Other ways
  5. Open the panel and activate. Start After Effects or Premiere Pro, then Window > Extensions > the tool's name. Paste the license key from your Gumroad receipt and click Activate. One key works on 3 computers. It needs internet once, then works offline.

Something not working?

I don't see the tool in Window > Extensions
  1. Fully quit After Effects / Premiere Pro and open it again. New panels only appear after a restart.
  2. Make sure you ran the installer from the unzipped folder, not from inside the ZIP.
  3. Run the installer once more and wait until the window says it's done.
  4. Kreevo Voice in Premiere: Preferences > Audio > Audio Plug-In Manager > Scan for Plug-Ins, then restart Premiere.
  5. Still missing? Do the manual install below.
Manual install (if the installer doesn't work)
  1. Copy the tool's folder (for example MotionType) into:
    %APPDATA%\Adobe\CEP\extensions\~/Library/Application Support/Adobe/CEP/extensions/ Paste that path into the File Explorer address bar and press Enter. Create the extensions folder if it's missing. In Finder: Go > Go to Folder, paste the path, press Enter. Create the extensions folder if it's missing.
  2. Allow Adobe to load it. Open Command Prompt and paste:
    for %v in (9 10 11 12 13) do reg add "HKCU\Software\Adobe\CSXS.%v" /v PlayerDebugMode /t REG_SZ /d 1 /f     Terminal and paste:
    for v in 9 10 11 12 13; do defaults write com.adobe.CSXS.$v PlayerDebugMode 1; done; killall cfprefsd
  3. Restart After Effects / Premiere Pro.
Mac: "Apple could not verify…" or "can't be opened"

This is normal for small tools that aren't sold through the Mac App Store. Don't move the file to the Trash. Use one of these:

  • macOS 15 or newer: double-click the installer, click Done, then System Settings > Privacy & Security > scroll down > Open Anyway, enter your password, click Open Anyway again.
  • macOS 14 or older: right-click the installer > Open > Open.
  • Works everywhere: open Terminal, type bash and a space, drag the installer into the window, press Enter.
Where is my license key?
  • In your Gumroad receipt email for that product.
  • Or open your Gumroad library, click the product: the key is shown above the download.
  • Bought the Bundle? Every tool has its own key. Open each tool in your library to see it.
  • Crash Guard, the SFX Pack and MotionType Lite don't need a key.
My key doesn't activate
  • Copy the whole key, without spaces before or after it.
  • Use the key of that tool. A MotionType key won't unlock Kinetic.
  • You need internet for the first activation.
  • One key works on 3 computers. Moving to a new computer? Email us and we'll reset it.
Which versions are supported?

After Effects CC 2019 or newer and Premiere Pro 2021 or newer (2026 included), on Windows 10/11 and macOS.
